# 商品级验收清单

状态：开发验证中，不能据此宣称零缺陷或完成正式商业发行。

## 发布标准

- 额度：未知不当零；过期不当实时；共享池不冒充独立模型额度；模型目录和额度分别标注来源与时间。
- 安全：无凭证进入 renderer、日志或发布包；IPC 只接受本地可信页面；禁任意导航、权限请求和新窗口。
- 连接：未配置有明确下一步；失败保留带时间的旧数据；单来源故障不导致程序退出。
- 协作：仅显式勾选执行；刷新不改选择；重复提交受阻；超时、失败和退出受控。不以发现 CLI 冒充已登录。
- 桌面：启动不等待网络；关闭/隐藏/托盘行为一致；升级不丢个人配置，有可操作回退。
- 分发：依赖和运行时版本一致；路径不能逃逸打包目录；干净构建不含 data/work/用户秘密；附许可和校验信息。
- 验证：单元、连接契约、模拟桌面流程、打包烟测各有可重复脚本。真实账号读数另列，测试数据不会进入正式数据目录。

## 本次明确边界

- 保留 Claude 原 statusLine 配置，不自动替换；未启用数据转发时只能显示待接入。
- WorkBuddy 当前为用户保存的网页快照，不宣称自动刷新。
- 不自动购买额度、不代用户登录、不运行付费协作来验证。
- 不自动推送、创建发行版或购买代码签名证书；未签名包应明示，不绕过 SmartScreen。
