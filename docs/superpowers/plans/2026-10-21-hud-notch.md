# QuotaDeck HUD 子项目 3：刘海胶囊、额度光晕与游戏时安静 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增"刘海"显示方式（顶部正中的黑块、按额度着色的呼吸光晕、提醒翅膀、停上去露出圆环），并在打游戏时把整个 HUD 藏起来，退出游戏后再出现。

**Architecture:** 主进程新增：
- 设置项 `style`（`strip` / `notch`）和 `games` 名单；
- 刘海布局：窗口放在顶部正中，并告诉页面黑块的位置；
- 游戏检测：常驻 PowerShell 小进程只上报原始事实，判定规则写在 JS 纯函数里。

渲染层新增：
- 纯函数模块 `hud-notch-metrics.js`：光晕色标、呼吸周期、翅膀里显示哪条提醒、闪光颜色；
- 显示模块 `hud-notch.js`。

卡片、提醒、批准都复用现有组件。

**Tech Stack:** Electron 44、Node 24 `node:test`、Windows PowerShell（`Add-Type` 调用 user32 / shell32），无新依赖。

**Spec:** `docs/superpowers/specs/2026-10-21-hud-notch-design.md`

## Global Constraints

- 只做 Windows，不为 Mac 做准备；不新增 npm 依赖，不用原生模块。
- 刘海和贴边浮条二选一；`style` 默认为 `strip`。
- 刘海收起时 200 × 30，下方圆角 12，上方耳朵半径 8；纯黑，里面不放任何东西。
- 翅膀展开时宽 456（= 200 + 2 × (112 + 16)），高 38，下方圆角 14。
- 光晕：向外 14，模糊 8，亮度 0.9，只向外发散。色标位置为 (i + 0.5) / n，HUD 顺序是 Codex、Claude、Antigravity、WorkBuddy、DeepSeek。档位色 `#3ddc84` / `#ffd23f` / `#ff453a`，无读数 `#9a9aa0`；全部无读数时整圈灰色、不呼吸、透明度 0.35。
- 呼吸：透明度在峰值和峰值 × 0.4 之间往返；有会话在跑时周期 3000 ms，否则 7000 ms。
- 事件闪光：一次 1800 ms，只闪那一家对应的那一段。reply 用 `#82aaff`；waiting、approval、error 用 `#e9a16d`。
- 翅膀里显示哪条：approval > waiting > error > reply，同级取最新。右翼文案：`Approve?` / `Waiting` / `Stopped` / `New reply`，同一家多条时加 `×N`。
- 鼠标停 400 ms 后展开、离开 200 ms 后收回；`cubic-bezier(.2,.8,.2,1)`，400 ms。只显示圆环，不显示数字。
- 卡片挂在黑块正下方，间距 6；刘海不能拖动。
- 游戏判定：`notification === 3`（`QUNS_RUNNING_D3D_FULL_SCREEN`），或者窗口占满全屏 && (路径含 `\steamapps\common\`，或 exe 在 `games` 名单里)。名单默认 `['cs2.exe', 'tlou-ii.exe', 'tlou-ii-l.exe', 'javaw.exe']`，不区分大小写。
- 游戏中：HUD 窗口隐藏，打开的卡片关掉，提醒照常攒着，`settings.visible` 不变。退出游戏后约 2 秒内恢复，光晕补闪一次。
- 检测进程每 1500 ms 检查一次，只在状态变化时上报；退出后自动重启，一分钟内最多 3 次；起不来时当作"没在打游戏"。

## Review Focus

1. **用户在托盘里隐藏了 HUD，然后进出游戏** → 退出游戏后不能自己冒出来 → Task 3 测试 `leaving a game does not show a HUD the user hid`。
2. **检测进程反复崩溃或一开始就起不来** → HUD 照常显示，不能卡在"游戏中"而一直藏着 → Task 2 测试 `a probe that keeps dying gives up and reports not gaming`。
3. **游戏中来了批准请求** → 窗口仍然藏着，提醒攒着，退出游戏后翅膀显示 `Approve?` → Task 3 测试 `alerts pushed while gaming are delivered when the game ends`，以及 Task 7 冒烟。
4. **从刘海切回贴边浮条** → 浮条回到原来的边和位置 → Task 1 测试 `switching style keeps the strip position`。
5. **设置文件里的 `games` 被手改坏了**（不是数组、含非法项） → 回到默认名单，合法项保留 → Task 1 测试 `games list is validated and kept across saves`。
